Example 4.5.4.

The equation \(2x+3y=6-2x\) implicitly defines \(x\) as a function of \(y\) and also implicitly defines \(y\) as a function of \(x\text{.}\) Rewrite this equation to give these functions explicitly.
🔗
First, to find \(x\) as a function of \(y\) means we want an equation that gives \(x\) as the output. So we solve for \(x\text{:}\)
\begin{align*} 2x+3y\amp =6-2x\\ 4x+3y\amp =6\\ 4x\amp =6-3y\\ x\amp =\frac{6-3y}{4} \end{align*}
🔗
We can rewrite this in function notation if we want as \(x=f(y)=\frac{6-3y}{4}\text{.}\)
🔗
Now to find \(y\) as a function of \(x\) we solve for \(y\text{:}\)
\begin{align*} 2x+3y\amp =6-2x\\ 3y\amp =6-4x\\ y\amp =\frac{6-4x}{3} \end{align*}
🔗
We can rewrite this in function notation also as \(y=g(x)=\frac{6-4x}{3}\text{.}\)
