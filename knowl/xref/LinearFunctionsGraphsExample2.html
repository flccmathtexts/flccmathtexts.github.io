Example 5.4.3.

Solve:
\begin{equation*} 1.43x-2.07(1.08x-2.75)=3.12+2.59(0.76x-3.55) \end{equation*}
🔗
This is actually a linear equation; we can see that if we were to simplify each side them both sides could be put into slope-intercept form. We don’t need to actually do this though.
🔗
Graphing Y1=1.43X–2.07(1.08X–2.75) and Y2=3.12+2.59(0.76X-3.55) in the standard window we get:
🔗
The intersection gives us the solution: \(x=4.24\) (rounded to two decimal places.)
