Example 5.2.6.

What is the vertical intercept for the linear function \(h(t)=3t-17\text{?}\)
🔗
Here we don’t know the intended meaning of the function, so we can’t rely on that to tell us the “starting point”. But we do know that the \(y\)-intercept happens where the input value is \(t=0\text{.}\) So, substituting in we get:
\begin{equation*} h(0)=3(0)-17=-17 \end{equation*}
🔗
And so we conclude that the vertical intercept is \(-17\text{.}\) Or, we could equally correctly say that the vertical intercept is \((0, -17)\text{.}\)
