Example 2.6.7.

Factor: \(x^2-25\)
🔗
Notice that there are only \(2\) terms in this expression, which suggests the coefficient of the “middle term” must be \(0\text{.}\) We can think of this expression as \(x^2+0x-25\text{.}\)
🔗
We can factor this by finding factors of \(-25\) whose sum is \(0\text{.}\) Our options are:
  • \(25, -1\) (sum \(24\))
    🔗
  • \(-25, 1\) (sum \(-24\))
    🔗
  • \(-5, 5\) (sum \(0\))
    🔗
We need the pair \(5, -5\text{.}\) Therefore, we factor \(x^2-25\) into \((x+5)(x-5)\text{.}\)
🔗
Checking with the distributive law:
\begin{align*} (x+5)(x-5) \amp = x(x)+x(-5)+5(x)+5(-5)\\ \amp = x^2-5x+5x-25\\ \amp = x^2-25 \end{align*}
🔗
The middle terms simplify to \(0\) because the integers used were opposites. When we have a second degree expression in the form \(a^2-b^2\text{,}\) we call it the difference of squares and factor it into \((a+b)(a-b)\text{.}\)
